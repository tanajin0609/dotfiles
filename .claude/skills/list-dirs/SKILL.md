# list-dirs — ディレクトリ一覧表示

## 実行方法

```bash
bash ~/.claude/skills/list-dirs/scripts/list_dirs.sh [起点パス] [深さ]
```

- 起点パス省略時: `~/projects`
- 深さ省略時: 3階層
- 対象はディレクトリのみ（ファイルは表示しない）
- 常に除外: `.git`, `node_modules`, `.venv`, `__pycache__`, `dist`, `build`, `.astro`, `.next`

## 使い方の例

- 「ディレクトリ一覧見せて」→ そのまま実行（デフォルト値）
- 「tech-blog の中身を見せて」→ `bash .../list_dirs.sh ~/projects/tech-blog`
- 「もっと深く見たい」→ 深さを4, 5と増やして再実行

## 出力後の対応

スクリプトの出力をそのまま会話に貼り付ける。加工・要約はせず、ユーザーが
次にどのディレクトリを指定するか選べる状態にする。

存在しないパスを指定された場合はスクリプトがエラーメッセージと共に終了する
（exit code 1）ので、そのエラーをそのまま伝える。
