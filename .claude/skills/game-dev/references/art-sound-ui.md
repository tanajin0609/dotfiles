# アート・サウンド・UI

## 素材の進め方

- **仮素材で面白さを確認してから本素材を作る**。四角形と仮の音で面白くないものは、絵を良くしても面白くならない。逆に、仕様が変わると本素材は作り直しになる。
- 仮素材でも、**大きさ・当たり判定・アニメーションのコマ数**は本番想定に合わせる。ここがずれると手触りの調整がやり直しになる。
- 一貫性を先に決める: 基準解像度、1マスの大きさ、色数/パレット、輪郭線の有無、視点。素材ごとに密度（1ドットの大きさ）が違うと、それだけで雑に見える。

## 素材の出どころと権利

Claudeは画像・音声の完成素材を直接作れない場面が多い。調達方法ごとに確認することが違う。

| 調達方法 | 確認すること |
|---|---|
| 自作 | 特になし（制作ツールの商用利用条件のみ） |
| 配布素材 | ライセンス（商用可否、改変可否、クレジット表記の要否）。素材ごとに出典URLとライセンスを一覧に記録する |
| 購入素材 | 利用範囲（本数・プラットフォーム・再配布の扱い） |
| 生成AI素材 | 生成サービスの利用規約と、公開先ストアの開示ルール。規約は変わるため公開前に公式で確認する |

クレジット一覧は最初の1個目を入れた時点から付け始める。公開直前に出典を遡るのは困難。

## 手触り（ゲームフィール）

同じルールでも、反応の付け方で気持ちよさが大きく変わる。コアループが固まった後、ベータ工程で入れる。

| 手法 | 内容 | 効く場面 |
|---|---|---|
| ヒットストップ | 攻撃が当たった瞬間に数フレーム止める | 打撃の重さ |
| 画面揺れ | 衝撃時にカメラを短く揺らす | 爆発・被弾（設定で切れるようにする） |
| のけぞり・点滅 | 当たった対象が反応する | 当たったことの伝達 |
| パーティクル | 破片・火花・土煙 | 接地・破壊・加速 |
| 伸び縮み | ジャンプで縦に伸び、着地で潰れる | キャラクターの生命感 |
| 緩急のある動き | 等速でなく、加速・減速をつける | UI・カメラ・移動全般 |
| 先行入力 | 少し早く押した入力を受け付ける | 連続ジャンプ・連続攻撃 |
| 猶予時間 | 足場を離れた直後もジャンプを許す | 「押したのに飛ばない」の解消 |
| 効果音の変化 | 同じ音の高さを毎回少し変える | 連続する音の単調さ防止 |

強さ・長さは必ず調整値として外に出す。かけすぎると見づらくなるため、人に強弱を判定してもらう。

## サウンド

- 効果音が先、BGMは後。操作への反応音（決定・攻撃・被弾・取得）があるだけで手触りが変わる。
- 音量は種類ごと（BGM/効果音/声）に分けて管理し、設定画面で変えられるようにする。
- 同じ音が同時に多数鳴ると割れる。同時発音数に上限を設ける。
- BGMは継ぎ目なくループするか確認する。場面転換は急に切らず、短く音量を下げてから切り替える。
- ブラウザは、ユーザーが操作するまで音を鳴らせない制限がある。最初のクリック/キー入力の後に音を開始する。

## UI

- **プレイ中の表示は最小に**。常時必要な情報（体力・残弾）だけを画面端に置き、中央の視界を塞がない。
- **画面サイズの違いに備える**。基準解像度と拡縮方法（比率固定で余白/引き伸ばし）を決める。スマホは切り欠きや角丸で隠れる領域を避ける。
- **入力機器に合わせて表示を変える**。ゲームパッドで遊んでいるのに「スペースキーを押す」と出さない。
- **全画面をキーボード/パッドだけで操作できる**ようにする（選択中の項目が見えること、戻る操作が一貫していること）。
- 最低限そろえる画面: タイトル、ポーズ、設定（音量・操作）、リザルト/ゲームオーバーからの即リトライ。
- 文字は直接コードに書かず、識別子で引く形にしておくと後から多言語化できる（多言語対応がスコープ外でも、手間は小さい）。

## アクセシビリティ

後付けより最初から入れるほうが安い項目。

- 色だけで区別しない（敵味方・属性は形や記号でも区別する）
- 画面揺れ・点滅を切る設定
- 文字サイズと背景とのコントラスト
- 操作の割り当て変更、長押しと切り替えの選択
- 音でしか伝えない情報を作らない（字幕・視覚的な合図）

画面の使いやすさ全般の確認は uiux-review skill を併用する。
