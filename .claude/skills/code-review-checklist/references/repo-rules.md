# リポジトリ固有ルールの読み込み（合図方式）

レビュー対象リポジトリに `.claude/review-rules/INDEX.md` があれば読む。無ければ何も言わずに飛ばす。

## INDEX.md の書式

```markdown
| ID | 合図（差分に対する正規表現） | 対象パス（glob） | ルール（1行） | 詳細 |
|----|------------------------------|------------------|---------------|------|
| R1 | `gomock\.Any\(\)` | `**/*_test.go` | ctx以外は具体値で照合する | testing.md#mock |
```

- ルール本文は `詳細` 列のドキュメント（INDEX.md と同じディレクトリからの相対パス）に置き、INDEX.md は索引に徹する。
- linter/CI で機械的に担保できるルールは載せない（文字列の有無だけで違反が決まるものは linter 側へ寄せる）。

## 適用手順

1. 差分の追加行（`+` 行）に対して各行の合図を機械的に照合する。対象パスが指定されていればそのファイルに限る。
   ```bash
   git diff <base>...<head> -U0 -- '<対象パス>' | grep -E '^\+' | grep -E '<合図>'
   ```
2. ヒットしたルールの `詳細` だけを読み、「この箇所で本当に違反か」を判断する。ヒットしないルールの詳細は読まない
   （全ルールを確認しようとすると差分と無関係なコードまで読み始め、精度とコストが悪化するため）。
3. 適用した/ヒットしなかったルールIDを報告の末尾に1行で列挙する（例: `repo-rules: 適用 R1,R4 / 該当なし 他12件`）。
